🧴 SkinlyCare

SkinlyCare is a modern and responsive skincare website designed to provide users with a simple, smooth, and engaging shopping experience.

The website helps users explore skincare products, learn more about their skin needs, discover suitable products through a Skin Quiz, and manage their cart and wishlist.

✨ Features

- 🏠 Home Page with a modern hero section and skincare content
- 🧴 Products Page to browse available skincare products
- 🔍 Product Details with images, descriptions, ratings, prices, and ingredients
- 🧠 Skin Quiz that recommends a suitable product based on the user's answers
- 🛒 Shopping Cart with add, remove, and quantity controls
- ❤️ Wishlist for saving favorite products
- 🌙 Dark Mode for a comfortable browsing experience
- 📱 Responsive Design for different screen sizes
- 🔝 Back to Top Button
- 💾 Local Storage to preserve cart, wishlist, and theme preferences
- 📱 Mobile Navigation Menu
- 📝 Blog Section for skincare-related content
- 📩 Contact Us Page

🧠 Skin Quiz

One of the main features of SkinlyCare is the interactive Skin Quiz.

Users answer a series of questions about their skin concerns, preferences, and skincare goals.

Based on their answers, the system calculates the most suitable product and displays a personalized recommendation.

The quiz is connected to the same product data used throughout the website, keeping product information and images consistent.

🛒 Cart & Wishlist

The website uses JavaScript and Local Storage to manage the shopping cart and wishlist.

Users can:

- Add products to the cart
- Remove products from the cart
- Increase or decrease product quantity
- Add or remove products from the wishlist
- Keep their saved items when navigating between pages

🌙 Dark Mode

SkinlyCare includes a dark mode feature that allows users to switch between light and dark themes.

The selected theme is stored using Local Storage, so the user's preference remains saved when they revisit the website.

📱 Responsive Design

The website is designed to work across different screen sizes, including:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet

Media queries and responsive layouts were used to provide a consistent user experience on different devices.
